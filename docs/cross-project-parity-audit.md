# Cross-project parity audit

Teenage Mutant Ninja Turtles: Turtles in Time Re-Shelled against the three other ReXGlue recompilation projects of the same author: Hard Corps: Uprising Recompiled (HC), Geometry Wars: Retro Evolved 2 Recompiled (GW2) and Super Street Fighter II Turbo HD Remix Recompiled (SSF2T). All four pin ReXGlue v0.10.0 (`f5337cdc`), so patch files are directly comparable.

## How the audit was done

- Every commit of `git log --all` of each reference was read, oldest to newest: **143 (HC), 129 (GW2), 54 (SSF2T), 326 in total**. Appendices A to C hold one row per commit.
- A change that a later commit fixed, reworked or removed was judged by its final form, never by the first commit.
- Every shared source, test, tool, CMake, packaging and patch file was compared by behaviour after normalising project names. "Already present" always names a TMNT file that was read.
- Every same-named SDK patch of the references (56 to 58 per project) was compared byte for byte with the TMNT patch. TMNT carries the whole reference series; the differences are cvar prefixes, comments, context offsets and TMNT being newer (0039). TMNT descends from the HC template, which is why most infrastructure was already present.
- Nothing was built or launched. Checks used: static reading, `git apply` of both platform series onto the pinned SDK commit, PowerShell parsing, `bash -n`, and small headless test programs (GPU plugin check, updater, session log and filter, file dialog backends).

Status values: ALREADY PRESENT, PORT, PORT WITH ADAPTATION, NOT APPLICABLE, REJECT, NEEDS RUNTIME TEST. The status is the classification at audit time; "DONE" in the last-but-three column says what this branch changed.

## 2. ReXGlue patches: Windows and Linux

`patches/rexglue-sdk/patches.txt` classifies every patch (platforms, targets, origin, parity). `tools/test.ps1` checks it against the files, the names and `docs/rexglue-runtime-patch.md`, and applies both series to the pinned SDK commit (83 patches: 54 shared, 18 Windows-only, 11 Linux-only; the Windows series has 72 patches, the Linux series 65).

- Windows patch with a Linux counterpart: 0011-0014 (D3D12 submissions, transfers, stencil, EDRAM) with 0016-0018; 0023 with 0024; 0027 with 0026; 0031 with 0032; 0037 with 0038.
- Windows only, nothing to port: 0015 (high-resolution sleep), 0041 sampler memo, 0044 async submission, 0049 host threads off CPU 0, 0052 ThinLTO, 0053 unchanged constant writes, 0056 PGO.
- Windows only, Vulkan candidates deferred (cannot be profiled or verified here): 0040 transfer short-circuit, 0055 per-draw loops, 0079 per-draw vertex residency (stale geometry possible), 0080 AA838 Stage A fix (the cyan flicker may still show on Linux).
- Linux only: 0019, 0021 (POSIX waits), 0034, 0035 (Vulkan), 0046 (SDL video guidance), 0082 (module library).
- Made common in this branch: 0051, 0054, 0081.

## 3. Deferred and rejected

Deferred, each with the reason: Vulkan equivalents of 0040, 0055, 0080 (no Linux build to verify); game-side fence waiter and native memcpy (need reverse engineering and a profile); runtime check of the Windows launcher XInput reader (ported, idle and replug test pending); VERSIONINFO resource (needs a build); `-rcN` version suffix; shutdown-order probe and presenter pacing test; negative updater tests; release notes (not prepared on request); `docs/rexglue-reference/`.

Rejected: HC 0058 tile heap debug patch, GW2 0056 frame trace and 0057 HDR/float resolve copies, SSF2T 0049 progress wake and the guest sign-in half of 0053, all DEBUG_SAULO instrumentation, every game-specific feature (cheats, skip intro, aspect hooks, interpolation, achievements, saves).

## 4. Linux and AppImage status

Static only; no Linux build or AppImage was produced. `tools/package-linux.sh` pins the AppImage tool by SHA-256, builds the FUSE-fallback runtime from the pinned source (`patches/appimage-runtime/baseline.env`), refuses hosts other than Ubuntu 20.04 and runs the glibc and content scans on the AppDir and on the extracted final image. The highest required GLIBC, GLIBCXX and CXXABI are therefore **not measured yet**: the script prints them per file on the first Linux build.
